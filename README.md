One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer: before deleting a function, ask your agent what it does — if neither of you knows, that's your answer. Written for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty.

## Run it

```sh
node main.ts
```

Writes the tip to `/output/entry.txt` (or `$OUTPUT_PATH` when set), with no trailing newline.
